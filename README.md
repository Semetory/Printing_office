# Типография

Типография — полиграфическое производственное предприятие, осуществляющее выпуск печатной продукции: книг, газет, журналов, рекламных материалов (листовок, буклетов) и их упаковки. 
Сайт типографии представляет собой программную реализацию, как визуальной составляющей так и программной реализации для приема обработки и хранения заказов типографического производства. 
Позволяя пользователю как клиенту выбрать необходимый ему шаблон для печати и загрузить материал для печать как его собственной продукции для личного использования, так и для печати продукции компании при заказе юридическим лицом.
