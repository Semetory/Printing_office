# Пояснительная записка к курсовому проекту

## Введение

В настоящее время интернет-технологии позволяют пользователям получать различные услуги дистанционно, включая заказ полиграфической продукции. Однако большинство существующих сайтов типографий либо предоставляют только справочную информацию о стоимости услуг, либо требуют отправки заявки для получения расчета стоимости заказа. Это усложняет процесс взаимодействия клиента с типографией и увеличивает время принятия решения о заказе.

Дополнительной проблемой является безопасность расчета стоимости продукции. На некоторых ресурсах итоговая цена рассчитывается на стороне клиента и передается на сервер без повторной проверки, что создает возможность подмены стоимости заказа.

В связи с этим была сформулирована цель курсового проекта:

Разработать веб-ресурс типографии для автоматизации расчета стоимости полиграфической продукции, оформления заказов и управления ими через административную панель.

Для достижения поставленной цели необходимо решить следующие задачи:

1. Определить сценарии использования веб-ресурса для клиентов и администраторов.
2. Спроектировать архитектуру клиент-серверного приложения и структуру базы данных.
3. Реализовать и протестировать прототип веб-ресурса типографии.

# 1. Функциональное назначение программного средства

## 1.1 Классы решаемых задач

Разрабатываемый веб-ресурс предназначен для решения следующих классов задач:

* задачи поиска информации о полиграфической продукции;
* задачи расчета стоимости полиграфических услуг;
* задачи оформления и сопровождения заказов;
* задачи хранения и обработки пользовательских макетов;
* задачи управления тарифами и заказами;
* задачи обеспечения безопасности административного доступа;
* задачи оптимизации трудозатрат сотрудников типографии при обработке заказов.


## 1.2 Функциональное назначение

Программа предназначена для автоматизации процессов расчета стоимости, оформления и сопровождения заказов полиграфической продукции.

Пользователь имеет возможность:

* просматривать каталог продукции и форматов бумаги;
* выполнять расчет стоимости заказа в режиме реального времени;
* выбирать параметры печати и дополнительные услуги;
* загружать макеты для печати;
* оформлять заказ;
* выбирать способ оплаты;
* отслеживать статус заказа по его номеру.

Администратор имеет возможность:

* проходить аутентификацию в системе;
* просматривать и изменять стоимость услуг;
* управлять заказами;
* создавать резервные копии базы данных;
* выполнять восстановление данных.

## 1.3 Нефункциональные требования, ограничения и интерфейсы

К программному средству предъявляются следующие нефункциональные требования:

* расчет стоимости заказа должен выполняться исключительно на сервере;
* данные, полученные от клиента, должны проходить валидацию;
* интерфейс должен корректно отображаться на мобильных устройствах и персональных компьютерах;
* административная панель должна быть защищена от перебора паролей;
* система должна поддерживать резервное копирование базы данных;
* приложение должно функционировать в архитектуре клиент-серверного взаимодействия по протоколу HTTP/HTTPS.

Техническое задание представлено в приложении 3.

# 2. Проектная часть

## 2.1 Архитектура приложения

Для обеспечения удобства сопровождения, расширяемости и разделения ответственности была выбрана клиент-серверная многослойная архитектура.

Основными компонентами приложения являются:

* пользовательский интерфейс (HTML, CSS, JavaScript);
* REST-контроллеры Spring Boot;
* сервисный слой бизнес-логики;
* слой доступа к данным (Spring Data JPA);
* база данных PostgreSQL.

Архитектура построена по принципу разделения на слои:

* Presentation Layer;
* Business Logic Layer;
* Data Access Layer.

Выбор архитектуры представлен в приложении 4.

# Заключение

В ходе выполнения курсового проекта был разработан веб-ресурс типографии для автоматизации расчета стоимости и оформления заказов полиграфической продукции.

В результате выполнения работы были реализованы следующие функции:

* просмотр каталога продукции;
* расчет стоимости заказа в режиме реального времени;
* оформление заказа с загрузкой макетов;
* отслеживание статуса заказа;
* управление тарифами через административную панель;
* защита системы аутентификации от перебора паролей;
* резервное копирование и восстановление базы данных.

Разработанный программный продукт обеспечивает автоматизацию основных бизнес-процессов типографии, повышает удобство взаимодействия клиентов с компанией и может быть использован в качестве основы для дальнейшего развития коммерческого интернет-ресурса.
