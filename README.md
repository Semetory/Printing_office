# Типография
Типография — полиграфическое производственное предприятие, осуществляющее выпуск печатной продукции: книг, газет, журналов, рекламных материалов (листовок, буклетов) и их упаковки.
Сайт типографии представляет собой програмную реализацию, как визуальной составляющей так и програмной реализации для приема обработки и хранения заказов тмпографического производства. Он позваляет
пользвателю как клиенту выбрать необходимый ему шаблон для печати и закгрущзить материал для печать как его собственой продукции для личного использования, так и для печати продукции компании при 
заказе юридическим лицом.
